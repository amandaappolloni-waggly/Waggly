# Waggly

Walk your dog with your friends, even when they're far away.

This is the beta test version: record walks with your phone's GPS, keep a monthly streak, race friends in a monthly showdown, see friends' walks, give paws, and cheer friends on while they walk.

- **Open on iPhone:** visit the site in Safari, tap **Share → Add to Home Screen**.
- **Try without an account:** add `?demo=1` to the address.
- **Database setup:** run `supabase/setup.sql` in the Supabase SQL Editor, then fill in `config.js`.
